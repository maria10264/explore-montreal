## Features

- 🗺️ Interactive Montreal map with event locations
- 🔎 Search events by name
- 🏷️ Filter events by category
- 🌤️ Filter events by season
- 📅 Sort events by date
- 📍 View detailed information about activities
- 🖼️ Montreal highlights section showcasing major events

---

## Technologies Used

### Frontend
- React
- TypeScript

### Backend
- Node.js
- Express
- TypeScript

### Data
- JSON-based dataset
- Processed and structured event data

## Installation

Clone the repository:

```bash
git clone https://github.com/maria10264/explore-montreal.git
cd explore-montreal


Running the Backend

Open a terminal:
cd server
npm install
npm run dev
Backend runs on:
http://localhost:3000


Running the Frontend

Open another terminal:
cd client
npm install
npm run dev
Frontend runs on:
http://localhost:5173


-----------------------------------------------------------------------

### Application Workflow

- The Express backend provides Montreal event data through API endpoints.
- The React frontend retrieves data from the backend.
- Users can search, filter, sort, and explore events.
- Events are displayed through interactive cards and an interactive Montreal map.
